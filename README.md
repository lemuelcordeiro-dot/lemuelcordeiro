# lemuelcordeiro
O assunto escolhido foi sobre o livro "Hábitos Atômicos" do James Clear pela sua clareza e objetividade em tratar do assunto de forma detalhada e diferenciada. O objetivo com esse trabalho é trazer dicas e insights e diversificar a forma como estudamos e entendemos os hábitos para poder mudar alguns comportamentos e narrativas de vida.
